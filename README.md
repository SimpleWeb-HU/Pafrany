## Futtatás

A demó szerver nélkül is megnyitható: elég duplán kattintani bármelyik HTML fájlra (a magyar oldalak a `hu/` mappában vannak, a nyelvválasztóval is át lehet váltani). Az `app.css` és az `app.bundle.js` lefordítva benne van a csomagban.

**Helyi megnyitás (file://):** a böngészők egy része ilyenkor letiltja a külön fájlból töltött webfontokat (Firefoxban a `hu/` alól a `../assets/fonts` is tiltott), és a font-preload hibát ír a konzolra. Ezért a `<head>` egy kis inline scriptje helyi megnyitáskor az `assets/css/fonts-local.css`-t tölti be: ebben ugyanaz a hat Jost WOFF2 van data URI-ként. Szerverről futtatva ez a fájl nem töltődik be, helyette a szokásos font-preload megy. **A `fonts-local.css` csak a demó része, Crownba nem kell átvenni**; ott az `assets/fonts/` fájljai és a `_fonts.scss` az irányadók.

Ha az SCSS-t vagy a JS-t módosítod:

```bash
npm install
npm run build       # build:css + build:js
npm run build:css   # assets/scss → assets/css/app.css (Bootstrap 5.3 SCSS-ből, nem CDN)
npm run build:js    # assets/js/app.js + components/*.js → assets/js/app.bundle.js (esbuild, IIFE)
npm run serve       # opcionális helyi szerver: http://localhost:4173
```

**JS:** a forrás ES modul (`assets/js/app.js`, amely importálja az `assets/js/components/*.js` fájlokat). Ezt kapja meg Józsi a Crown `resources/js/project/public/` mappájába, a saját buildjével. A statikus demó a lefordított `app.bundle.js`-t tölti be sima `defer` scriptként, így `file://` alól is működik. Ha a bundle nem töltődik be, az `onerror`, illetve egy 2,5 mp-es fallback leveszi a `js` osztályt, így minden tartalom látható marad.

## Mozgás (motion)

- Fájlok: `assets/js/components/motion.js`, `assets/scss/components/_motion.scss`. Crownban: `resources/js/project/public/components/motion.js`, `resources/scss/project/public/components/_motion.scss`.
- Tokenek:
  - görbe: `--motion-ease-out: cubic-bezier(.22,1,.36,1)`
  - időtartamok: hover 150 ms, UI 250 ms, belépő 450 ms, hero 700 ms
- `data-motion="fade-up"`: hero tartalom, cikkfej, kiemelt kártyák (21 helyen).
- `data-motion="stagger"`: pillérkártyák (Home, Concept) és a lakástípus-kártyák (Residences). A közvetlen gyerekek 60 ms-onként indulnak, legfeljebb 6 elemig.
- Rejtett kezdőállapot csak `html.js` mellett van, és `data-crown-render-mode="visual_edit"` alatt nincs. Reduced motion esetén nincs mozgás.
- Fejléc: a világos sáv egyetlen `::before` réteg, amelyet `clip-path: inset()` tár fel (700 ms, `cubic-bezier(.22,1,.36,1)`), így a logós sáv és a menüsor egyben jelenik meg. A menüsor tartalma 180 ms késleltetéssel jön be: opacity + 8 px translate, 450 ms; záráskor 150 ms. A két logó opacity-vel vált (250 ms), a szövegszín 250 ms. A fejléc fix pozíciójú, ezért layout shift nincs. A `clip-path` a skill alapszabályán (transform/opacity) túli kivétel: egy fix elem kitakarása, más elem helyét nem érinti.
- Kivételek:
  - színváltás hoverre (≤ 250 ms)
  - a GYIK/harmonika natív `<details>` nyitás, magasság-animáció nélkül; csak a plusz/nyíl ikon fordul el (transform, 250 ms)
- Crown-szöveg DOM-ját JS nem bontja szét. Külső animációs lib nincs.
- Az init-függvények idempotensek (`data-*-init` jelölő).
